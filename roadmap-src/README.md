# Две мастерские: полный лист и бюджет около $5000

Рабочая копия — /srv/tree-of-father на сервере. Публикация — /roadmap/. Редакция от 09.11.2026, ownerRevision=3.

## Подтверждённые условия

Владелец уточнил ориентир $5000 с разумным увеличением, полный лист LowRider, предпочтение самостоятельного металлического стола, покупную недорогую сосну небольшого диаметра, горизонт оборудования 2–3 года, свой универсальный принтер и новую многоразовую полумаску (сейчас только одноразовые).

Формат листа и помещение ещё уточняются. База — фанера 1220×2440, поле 1250×2500, предварительный стол 1600×2900. Для МДФ 1830×2600 есть отдельный вариант поля 1860×2660 с предупреждением о габарите/жёсткости. До подтверждения формата металл не раскраивать.

15 этапов, 46 альтернативных строк покупок, группы механики и 18 строк печатных деталей. Стеклопластик и ленточная пилорама исключены из текущего плана; исходное дерево навыков и пользовательская история сохранены.

## Закупки

Основной кандидат принтера — K2 Pro без CFS за ARS 1 485 000 по переводу у Reset Argentina: первичная карточка и JSON-LD подтверждают цену/наличие на момент проверки. 300³ мм и нагрев камеры 60°C — по Creality. Состав пластика, запчасти, гарантию и точную доставку уточнить до оплаты. P1S и Flashforge остаются альтернативами. Число/тип катушек из набора надо вычесть из отдельной строки PLA после подтверждения.

Для регулярной стали выбран класс MIG/MAG с газом 180–200 А; EVOMIG-220 — кандидат по проверяемым спецификациям/цене, без заявления о доказанном ресурсе. Газ, защита и УШМ включаются отдельным выбором. Для одного стола допустимы болтовая сборка/услуги. Алюминий и AC/DC TIG отложены до конкретных задач. Проверка электрики учитывает нагрев принтера и нагрузку сварки, не назначает автомат/кабель заочно.

Смета показывает запуск без этапа обработки сухой партии, полное завершение и добавление собственного MIG. Перенос рейсмуса не вычитается из полной стоимости. Суммы с 15% резервом при условном 1535 ARS/USD: запуск K2+сталь примерно $4388–6587; всё со своим рейсмусом $5262–7890; плюс MIG $6173–9171. Это диапазоны неполных котировок, не гарантия вместиться в бюджет. Пользователь меняет эффективный курс и конкретные цены.

Оценки стола, труб и усилителей масштабируются по размерам относительно 1250×2500; реальный раскрой и фрахт это не заменяет. В увеличенном варианте при недостаточности 8 м ремня kit добавляется цельный отрезок для X. Собственные введённые цены не масштабируются — их надо перепроверять после изменения поля.

## Данные и сохранность

Страница читает GET /api/tech, не вызывает POST и не меняет инвентарь, XP, проекты, часы или платежи. Имеющееся исключается из будущих затрат. Подтверждённая новая полумаска не исключается общей старой отметкой respirator.

localStorage roadmap-minimal-v2 сохранён; ownerRevision=3 обновляет только условия новой постановки, оставляя отметки и индивидуальные цены. Старый roadmap-v1 не перезаписывается. Экспорт включает план, отметки и прежний ключ. Между устройствами отметки дорожной карты пока не синхронизируются.
