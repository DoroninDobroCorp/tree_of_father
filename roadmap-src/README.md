Новый активный план ограничен двумя результатами: бревно → сухая ровная доска и домашний LowRider 4. Исходные дерево навыков, журнал опыта, инвентарь, план часов и платежи не изменяются.

## Источники и допущения

roadmap-data.json содержит 14 этапов, 39 альтернативных строк покупок, полную ведомость групп механики и 18 строк печатных файлов. Технические факты сверены по V1, производителям пилы/рейсмуса/принтеров и 3M; импорт — по ARCA. Все первичные ссылки и даты встроены в страницу. Цены с карточек продавцов отделены от оценок фрахта и целевых бюджетов.

Не получены индивидуальные котировки печатника, резчика и курьера. Не подтверждена применимость pequeños envíos к пяти одинаковым моторам и производственному использованию. Стартовый бюджет, размеры помещения/изделий, брёвна, модель маски и необходимость ширины рейсмуса более 330 мм пока неизвестны. Эти неопределённости показаны пользователю, заказы и внешние сообщения не отправлялись.

Базовый расчёт: поле 600×900 мм, 1–2 коротких бревна мягкой древесины и сушка под существующей крышей. Размеры 1220×1220/2440 доступны в калькуляторе, но цены материала автоматически от поля не масштабируются. 1535 ARS/USD — старое исходное значение, явно не выдаётся за текущий курс.

## Данные пользователя

Страница только читает GET /api/tech для инвентаря, использует снимок при недоступности и не вызывает POST. Имеющееся исключается из будущих покупок. Класс и модель респиратора неизвестны, поэтому для него предусмотрен явный выбор «используем свой / резерв на замену».

Отметки нового плана хранятся в localStorage roadmap-minimal-v2 и экспортируются вместе с планом, инвентарём и прежними отметками. Старый ключ roadmap-v1 не перезаписывается. Старые отметки этапов не переносятся на изменённые по смыслу этапы автоматически.

Исходные roadmap.html и roadmap-src/{template.html,roadmap-data.json,build_roadmap.py} сохранены до изменений в /home/ubuntu/tree-of-father-revisions/20261109T164753Z-minimal-plan/. Там же SHA256 сохранённых основных пользовательских файлов.

## Сборка и проверки

python3 roadmap-src/build_roadmap.py --output /tmp/roadmap-preview.html
node tests/minimal-roadmap.test.js
python3 roadmap-src/build_roadmap.py

Сборка проверяет уникальность и ссылки, зависимости без циклов и диапазоны цен, затем заменяет HTML атомарно. Тест исполняет настоящий JS шаблона в изолированном DOM, проверяет 8 представлений, геометрию по формулам V1, взаимоисключающие варианты, исключение инвентаря, статусы, индивидуальные цены, курс ARS, нулевой выход доски и сохранность прежних отметок.

На опубликованной странице в браузере проверены: чтение инвентаря с сервера, размеры полного листа, исключение повторных XZ при V1 kit, замена заказной печати собственным принтером, скрытие имеющегося штангенциркуля, возврат тестовых настроек, экспорт JSON и раскрытие инструкций. На фактическом узком экране 363 px горизонтального переполнения страницы нет; таблицы прокручиваются внутри. Ошибок JS в консоли при проверке нет.

Ни один физический станок этим исследованием не собран и не испытан. Публичный HTML совпал с серверной сборкой, основные страницы и API отвечают HTTP 200; исходные data/save.json, data/workshop.json, index.html, tech.html и workshop.html совпали с контрольными SHA256 перед работой.
