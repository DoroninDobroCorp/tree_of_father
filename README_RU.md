# Своя мастерская · Skill RPG

Личная карта maker/DIY-навыков, реальные проекты и журнал опыта. Для собственного дома и удовольствия, без гонки за профессией. Версия 1.0; формат данных v3.

## Быстрый старт

Откройте **index.html** в обычном браузере. Это однофайловая автономная игра: стили, код и начальный каталог уже внутри. Интернет, сервер, регистрация и установка библиотек для основных функций не нужны. Отдельный `maker_rpg.html` — идентичная копия этого файла.

При ограничениях предпросмотра откройте файл в полноценном браузере. Если браузер запрещает постоянное хранение, игра покажет предупреждение. В этом случае не закрывайте страницу до экспорта JSON; либо используйте локальный сервер ниже.

**Важное:** изменения сохраняются в хранилище браузера, а не переписывают HTML на диске. Периодически нажимайте «JSON» и сохраняйте резервную копию. Удаление данных сайта, другой браузер, другой адрес/порт или перемещение HTML могут отделить вас от прежнего сохранения. Экспорт/импорт JSON переносит весь профиль.

## Что внутри

- 14 крупных направлений, 164 конкретных навыка, 60 проектных карточек и 69 инструментов.
- Одна каноническая карточка навыка, много проектов со ссылками на неё. Общие операции не копируются в каждую профессию.
- Карточки с целью, упражнением, критерием результата, предпосылками, оснащением и обозначением риска.
- Дерево проработано глубже для домашней мебели; композиты содержат отдельный путь к стеклопластику и формам.
- Проекты с этапами, заметками, состояниями «В планах / В работе / Отложен» и отдельной записью результата.
- Журнал практики, теории, остановленных попыток и прошлого опыта. Изменение или удаление записи пересчитывает связанные XP.
- Ручное добавление/редактирование навыков, проектов и направлений; личные цели и заметки к навыкам.
- Справочник инструментов с названиями на испанском и личным статусом: использовал, есть, одолжить, хочу и т. д.
- Поиск, фильтры, светлая/тёмная тема, адаптивная вёрстка, резервные копии и отмена трёх последних изменений данных.
- ИИ-наставник: анализ опыта, развитие каталога, последовательности проектов. Только предложения, только после одобрения.

Начальный профиль содержит **восемь записей**, в том числе **два завершённых ремонта**. Душ и бачок — практика; просмотренный курс профчистки — немного теории; Fusion 360, Arduino, ESP и ручные инструменты — прошлый опыт. Точные даты выполнения не придуманы. Текущие протечки и неподтверждённые работы не засчитаны. Все стартовые записи и оценки можно уточнить.

## Как пользоваться

### Выбрать дело

«Карта навыков» → направление → навык. Внутри: что попробовать и как проверить результат. В правой части направления — связанные проектные карточки; это рекомендации, не обязательные экзамены.

«Проекты» → карточка → «В работу». Отмечайте этапы и фактические решения. Галочки не добавляют XP. Сначала физически закончите работу, затем нажмите «Завершил — записать результат». Проверьте список использованных навыков: даже у выполненного проекта не нужно автоматически засчитывать всё из шаблона.

Этапы — **учебный план, не подробная техническая инструкция** для опасной операции. Электрика, газ, высокое давление, высота, несущие конструкции и опасные материалы требуют отдельной подготовки и проверки применимых требований. Число XP не является квалификацией или разрешением работать.

### Записать опыт

Опишите результат, свой вклад и подтверждение. Можно оставить дату неизвестной. Выберите только действительно использованные навыки и небольшое количество XP. Запись требует отдельного подтверждения факта.

Правила:

| Вид записи | Что означает | Предел одной записи |
|---|---|---:|
| Завершённая практика | Реальная законченная работа | 80 XP |
| Теория | Действительно изученный материал | 20 XP |
| Прекращённая попытка | Практиковался, но работа окончательно остановлена | 15 XP |
| Прошлый опыт | Ранее делал, подробности и свежесть могут быть ограничены | 40 XP |

На один навык в одной записи — 1–30 XP. Это условные игровые числа, а не научная модель обучения. За повторные самостоятельные работы опыт возможен; точные дубли записей блокируются. Семантически похожие записи с другими формулировками всё равно должен проверять человек.

Текущие дела, покупки и планы не дают XP. Теоретическая запись, связанная с практическим проектом, не завершает этот проект. За сам факт добавления карточки и отдельно за проект бонусы не начисляются: нет двойного учёта одних и тех же действий. Прошлый опыт не обнуляется из-за паузы; «освежить» — напоминание, а не наказание.

## ИИ уже предусмотрен в двух вариантах

### 1. Через обычный чат — без API-сервера

В разделе «ИИ-наставник» выберите режим и напишите запрос. Например:

> Проработай дерево для простых столов, лавок и кровати. Уточни существующие карточки, предложи недостающие упражнения с проверяемым результатом. Опыт за планы не начисляй.

Нажмите «Подготовить запрос для чата». Игра соберёт правила, текущую ревизию, существующие ID, контекст и JSON Schema. Скопируйте пакет или сохраните `.txt`; передайте его в чат. Полученный JSON верните через «Вставить ответ JSON» либо загрузку файла.

Сначала появится предложение с причинами и изменениями «до / после». Выберите нужные пункты, затем нажмите «Применить выбранное». До этого карта не меняется. При необходимости есть отмена.

Пока ждёте ответ, **не изменяйте карту**. Предложение относится к конкретной ревизии; устаревший ответ отклоняется. В таком случае подготовьте новый пакет. Если ответ не соответствует формату, попросите чат исправить JSON по схеме из пакета.

Это ручной обмен с моделью в чате, не встроенная модель и не имитация автоматического запроса. Отдельная кнопка демо явно показывает заранее подготовленный пример; она ничего не отправляет в API.

### 2. Через OpenAI API — локальный backend уже включён

Нужен **Python 3.10+**. Для сервера не нужно устанавливать pip-пакеты, Node, npm, редактор кода или базу данных.

В терминале перейдите в распакованную папку проекта. Для macOS/Linux:

```bash
cp .env.example .env
# Откройте .env в редакторе и замените your_api_key_here своим API-ключом.
python3 server.py
```

Для Windows (PowerShell):

```powershell
Copy-Item .env.example .env
# Откройте .env в редакторе и укажите свой ключ.
py -3 server.py
```

Затем откройте в браузере:

```text
http://127.0.0.1:8765
```

На Mac также есть `START_MAC.command`. Если система не запускает его двойным кликом, используйте терминал. При занятом порте:

```bash
python3 server.py --port 8766
```

В настройках `.env`:

```dotenv
OPENAI_API_KEY=your_api_key_here
OPENAI_MODEL=gpt-5-mini
OPENAI_MAX_OUTPUT_TOKENS=12000
MAX_REQUESTS_PER_HOUR=20
PORT=8765
```

Модель — конфигурируемая настройка, не обязательный выбор навсегда. Сервер использует Responses API и Structured Outputs; выбранная модель должна поддерживать этот формат. После изменения `.env` перезапустите сервер.

В игре нажмите «Проверить сервер». Статус показывает наличие ключа в конфигурации; его действительность и баланс проверятся только при реальном запросе. Отметьте согласие на отправку контекста, затем нажмите «Получить предложение через API».

**Подписка ChatGPT и API имеют отдельный биллинг.** Этот сервер не использует лимиты чата и не обходит оплату API. Почасовой лимит сервера не является денежным бюджетом аккаунта. Проверьте настройки и расходы в кабинете API. При таймауте запрос уже мог быть обработан и тарифицирован; автоматических повторов сервер не делает.

Ключ хранится в `.env`/переменной окружения **на сервере**, не в HTML, запросах браузера, резервной копии или исходном каталоге. Не отправляйте `.env` в чат, Git или общую папку. В `.gitignore` он исключён. В архиве нет действующего ключа.

После перехода с автономного HTML на localhost прежний прогресс не появится автоматически: экспортируйте JSON в старой странице и импортируйте в новой.

## Границы текущей версии

Сервер рассчитан на один личный компьютер и слушает только `127.0.0.1`. Он не предназначен для публикации в интернет. Нет аккаунтов, облачной базы, фоновой синхронизации или совместного редактирования. С телефона карта работает как отдельный локальный профиль; перенос — через JSON.

Сохранения живут в браузере. Сервер не хранит журнал. Закрытие страницы теряет неподтверждённое предложение ИИ и несохранённый текст полей, но не уже сохранённые записи. Не редактируйте один профиль одновременно в разных вкладках.

Автономный режим работает без интернета. Автоматический ИИ требует соединения и API-ключа. Загрузка фотографий, поиск обучающих видео и просмотр внешних документов моделью в эту версию не входят. В журнале можно хранить текст, заметки и ссылки, но модель не получает изображения автоматически.

ИИ умеет добавлять/обновлять направления, навыки и проекты, архивировать навыки/проекты и предлагать новые записи опыта. Изменение справочника инструментов через ИИ пока не входит в контракт; он использует существующие ID инструментов. Безвозвратное удаление каталога и переписывание старого опыта моделью не разрешены.

```text
index.html                   Готовая автономная игра

src/seed.json                Полный начальный каталог и исходный опыт
src/build_data.py            Генератор исходного наполнения
src/core.js                  Проверки и расчёт опыта
src/app.js                   Интерфейс и логика приложения
src/style.css                Стили
src/shell.html               Шаблон единого HTML
src/proposal.schema.json     Строгий контракт предложений ИИ
src/build_schema.py          Генератор JSON Schema
src/ai_instructions.txt      Инструкции локального ИИ-сервера
src/build.py                 Сборка единого HTML
tests/                      Проверки правил, UI и backend
```

Для изменений интерфейса редактируйте `src/`, затем:

```bash
python3 src/build.py
```

Сборщик обновляет `index.html`, отдельную копию `maker_rpg.html` в родительской папке и инструкции AI backend. Генераторы `build_data.py` / `build_schema.py` запускать нужно только при изменении исходного каталога / схемы. Они не переписывают профиль, уже сохранённый в браузере: изменения каталога существующего профиля делайте через интерфейс/предложения или обдуманный импорт.

Проверки (опциональны для пользователя):

```bash
node tests/core.test.js
python3 -m unittest discover -s tests -p 'test_*.py' -v
# UI: отдельно установленные Playwright и Chromium, только для разработки
CHROMIUM_PATH=/path/to/chromium python3 tests/browser_smoke.py
```
