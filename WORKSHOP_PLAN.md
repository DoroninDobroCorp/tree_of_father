# План мастерской в часах

Открыть `/workshop/`. В дереве есть ссылка «План мастерской · часы». Карточки 46 маршрутов связаны с соответствующими этапами плана.

Первоначальные 101 шаг и 945 часов сохранены. Добавлено 31 направление, 169 шагов и 1047 часов: всего 270 шагов / 1992 часа. Это изменяемые оценки подготовки, проб и первых результатов; дальнейшие проекты добавляются самостоятельно. Паузы, доставка и ожидание роста растений не считаются рабочими часами.

В дереве сохранены прежние 391 навык, 120 исходных проектов и пользовательские дополнения. Каталог 7 добавляет 15 навыков и 46 проектов. Существующие записи опыта, отметки инвентаря, свои проекты и критерии прежних навыков сохранены. Галочка в плане не начисляет XP: журнал часов и журнал опыта решают разные задачи.

## Рекомендуемая последовательность

Порядок 46 направлений и пояснения восьми блоков заданы в `workshop-src/journey-order.json`. Сборка проверяет полноту списка и предшествование всех зависимостей направлений и исходных шагов. Номера этапов меняются, идентификаторы и ссылки остаются прежними.

Карта, группы шагов, ближайшие задачи и денежный ориентир используют один порядок направлений. Внутри направления сохраняется пользовательский порядок шагов. Перестановка вычисляется при отображении и расчёте: сохранённые шаги, фактические часы, платежи и исходная оценка не переписываются. Если задан месячный бюджет, его ориентир не зависит от перестановки. Если бюджет не задан, денежный ориентир следует новой последовательности; это ожидаемое изменение.

Блоки — рекомендуемые приоритеты. Можно начинать доступную ветку по интересу и нужному опыту, сад — по сезону, срочные ремонты — по необходимости. Для ЧПУ полезны предварительная работа с CAD, контроллером и пробными движениями: [документация LowRider](https://docs.v1e.com/lowrider/) и [настройка управления V1 Engineering](https://docs.v1e.com/software/). Сложность геометрии и сборки PrintNC сверена с [руководством проекта](https://wiki.printnc.info/en/v4/assembly). Выбранная последовательность — рекомендация для этого плана, а не требование производителей пройти остальные ремёсла.

## Данные и восстановление

- Дерево продолжает использовать `data/save.json`, свою историю отмены, резервные копии и Git.
- План использует отдельный `data/workshop.json`. Перед каждой новой версией предыдущая сохраняется в `data/workshop-backups/` (50 последних).
- `/api/workshop` наследует существующую проверку доступа сервера. POST требует исходную ревизию. Конфликт отвечает 409; чужая версия не заменяется.
- Повтор потерянного ответа с тем же id запроса не создаёт второй платёж или запись.
- В браузере остаются текущая, предыдущая и неотправленная копии. При конфликте сначала скачивается локальный JSON, затем загружается серверная версия.
- Экспорт HTML автономен. Кнопка «HTML с моими данными» включает актуальный прогресс. Импорт JSON поддерживает редакции 3 и 4.
- Дополнение `all-directions-v1` применяется один раз. Последующее удаление/архивация новых шагов не отменяется обновлением страницы.

## Сборка

Основное дерево: `python3 src/build.py`.
План: `python3 workshop-src/build_hours.py`; затем копировать `workshop-src/hours.html` в `workshop.html`, `workshop-src/expanded-data.json` в `workshop-data.json`.
Исходные 101 шаг и каталог находятся в `workshop-src/data.json`; новые направления — в `expansion-routes.json`, обзор — в `expansion-overview.json`, добавочные котировки — в `expand_data.py`. `hours-core.js` отвечает за расчёты, `hours-sync.js` — за серверное сохранение.

Изменение каталога дерева проходит через `src/seed.json` и сборку, которая дополняет историю хешей. Связи маршрутов: `src/workshop-links.json`. Для добавления новых идентификаторов этапов нужно также обновить `workshop-data.json` и перезапустить сервис: сервер проверяет ссылки по этому каталогу.

## Смета

Цены аргентинских продавцов сохранены в исходной валюте, интерфейс пересчитывает ориентиры в USD по выбранному пользователем курсу (исходный 1535 ARS/USD). Фактические платежи сохраняют собственный курс. Для новых направлений есть ориентиры Singer, Enertik, Elemon, Easy и Insumos para Ceramica. Ссылка, дата проверки, условия и качество подтверждения находятся в карточке покупки.

Это известная часть сметы: занятия, местная доставка, аренда и многие материалы требуют индивидуального расчёта. Сметы новых направлений явно неполные. Puzzi уже есть; строительный фен назначен один раз. Для дорогих направлений предусмотрено знакомство через студию, клуб, аренду или учебную площадку.

## Проверки

Проверены расчёты темпа и трудоёмкости, исторический валютный курс, сохранность старых данных, применение дополнения один раз, уникальность покупок, зависимости, добавление/изменение/архивирование шагов, перенос JSON/HTML, мобильная вёрстка, изоляция двух журналов, обрыв сети, повтор запроса, конкурентная запись и восстановление после конфликта. Тестовые записи создавались только на отдельном локальном сервере.
